# اوپن لاجک متن — پنجابی شاہ مکھی

ایہ اوپن لاجک پروجیکٹ دی ماورائے منطق تے رسمی طریقیاں دی درسی کتاب دا اے آئی نال کیتا گیا پنجابی شاہ مکھی ترجمہ اے۔ ایس ایڈیشن وچ سیٹ نظریہ، قضیاتی تے پہلے درجے دی منطق، نمونیاں دا نظریہ، حسابیت، ٹیورنگ مشیناں، نامکملیت، امکانی منطق تے ثبوت دا نظریہ شامل نیں۔

پڑھن لئی نستعلیق تے نسخ PDF، MathML تے 70 خاکیاں والا EPUB، تے براؤزر وچ کھلن والا HTML موجود نیں۔ دوویں PDF روپاں دی پوری LaTeX فائل نال دِتّی اے۔ ماخذ پیکج وچ 722 انگریزی ماخذ فائلاں، اوہناں دیاں 722 پنجابی فائلاں، فانٹ، خاکے، حوالیاں دی فہرست تے دوبارہ تیار کرن دے اوزار نیں۔ متن دی پڑھت وچ 718 اکائیاں نیں۔ چار متبادل ترتیب دیاں فائلاں اپنے متعلقہ حصیاں توں لبھدیاں نیں۔
